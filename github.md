# GitHub – Remote Hosting and Collaboration Platform

## What is GitHub?
GitHub is an online platform for hosting Git repositories and collaborating with other developers[cite: 36]. While Git tracks file history locally on your computer, GitHub stores remote copies of your projects online so they can be shared and reviewed[cite: 9].

## Key Concepts Learned in Class
- **Remote Repositories:** Connecting a local repository to GitHub with `git remote add origin <URL>`[cite: 42].
- **Syncing Code:**
  - `git push` – Uploads local commits to GitHub[cite: 44].
  - `git clone` – Downloads a full copy of a remote repository to your computer[cite: 45].
  - `git pull` – Fetches and merges the latest remote changes into your local branch[cite: 46].
- **Pull Requests (PRs):** Proposing changes from a feature branch to be reviewed, discussed, and merged into the `main` branch[cite: 56].
- **Forking:** Making your own copy of someone else's repository on GitHub so you can contribute changes independently[cite: 57].
- **Project Management Tools:** Using **Issues** to track bugs and tasks, **Projects** boards to organize progress, and **Releases/Tags** to mark important versions[cite: 62, 63, 64].

## Why It Is Useful
It serves as a cloud backup for your code, makes team code reviews structured through pull requests, and lets you showcase your work publicly[cite: 36, 40, 56].
