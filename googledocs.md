# Google Docs – Collaborative Cloud Writing

## What is Google Docs?
Google Docs is a free, web-based word processor that lets you create, edit, and share documents online from any device without needing to install desktop software.

## Key Concepts Learned in Class
- **Real-Time Collaboration:** Multiple team members can edit the same document at the same time and see each other's changes live.
- **Commenting & Suggesting Mode:** Reviewers can highlight text to leave comments or suggest edits without permanently overwriting the original draft.
- **Version History:** Google Docs automatically saves snapshots of the document over time, allowing you to view past edits and restore earlier versions if needed.
- **Sharing & Permissions:** Easy access control where you can share a link and set permissions to **Viewer**, **Commenter**, or **Editor**.
- **Exporting Formats:** Downloading finished documents in standard formats such as `.pdf`, `.docx`, or plain text.

## Why It Is Useful
It eliminates sending multiple file versions back and forth over email and makes team report writing simple and organized.
